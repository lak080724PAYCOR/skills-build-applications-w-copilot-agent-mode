# OctoFit Tracker Frontend

React 19 + Vite presentation tier for the OctoFit Tracker prototype.

## Available scripts

- `npm run dev` - start the frontend on port 5173
- `npm run build` - create the production build
- `npm run lint` - run Oxlint

The frontend calls the backend on port `8000` and will automatically use a Codespaces URL when `VITE_CODESPACE_NAME` is available.
